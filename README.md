# Калькулятор CI/CD

[![PHP CI Application](https://github.com/Arsen818/ci-cd-lab/actions/workflows/php-ci.yml/badge.svg)](https://github.com/Arsen818/ci-cd-lab/actions/workflows/php-ci.yml)

## Опис проєкту
Цей проєкт створено для демонстрації роботи CI/CD пайплайну з використанням GitHub Actions.

## Основний функціонал
- Додавання двох чисел
- Віднімання двох чисел
- Автоматичне форматування коду (Pint)
- Автоматичне тестування (PHPUnit)

## Інструкція із запуску тестів
Щоб запустити тести локально, виконайте наступну команду:

```bash
./vendor/bin/phpunit tests/Unit
